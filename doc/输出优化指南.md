## 🎨 输出格式化库

### 核心组件

**文件**：`lib/output_formatter.sh`

这是一个统一的输出格式化库，提供了丰富的格式化函数供所有脚本使用。

### 使用方法

```bash
# 在脚本中引入
source /root/setup_cdh_cluster/lib/output_formatter.sh

# 使用各种输出函数
log_success "操作成功"
log_error "操作失败"
print_header "步骤标题"
```

---

## 📋 可用的输出函数

### 1. 日志函数

| 函数 | 用途 | 示例 |
|------|------|------|
| `log_success` | 成功信息 | ✓ 操作成功 |
| `log_error` | 错误信息 | ✗ 操作失败 |
| `log_warning` | 警告信息 | ⚠ 需要注意 |
| `log_info` | 普通信息 | ℹ 提示信息 |
| `log_step` | 步骤信息 | → 正在执行 |

### 2. 标题函数

| 函数 | 用途 | 效果 |
|------|------|------|
| `print_header` | 主标题 | 蓝色双线框 |
| `print_subheader` | 子标题 | 青色分隔线 |
| `print_success_header` | 成功标题 | 绿色双线框 |
| `print_error_header` | 错误标题 | 红色双线框 |
| `print_warning_header` | 警告标题 | 黄色双线框 |

### 3. 状态显示

```bash
# 显示状态行
print_status "MySQL 服务" "ok" "运行正常"
print_status "httpd 服务" "fail" "未启动"
print_status "防火墙" "warn" "未关闭"
print_status "测试服务" "skip" "已跳过"
```

**输出效果**：
```
  ✓ MySQL 服务 - 运行正常
  ✗ httpd 服务 - 未启动
  ⚠ 防火墙 - 未关闭
  ○ 测试服务 - 已跳过
```

### 4. 表格显示

```bash
print_table_header
print_table_row "服务" "状态" "端口"
print_single_line
print_table_row "MySQL" "运行中" "3306"
print_table_row "CM Server" "运行中" "7180"
```

### 5. 提示框

```bash
print_tip "这是一个提示"
print_alert "这是一个警告"
print_error_box "这是一个错误"
```

### 6. 横幅

```bash
print_banner "CDH 集群部署" "自动化部署系统" "RaynLiu"
```

## 🎯 输出风格标准

### 颜色使用规范

| 颜色 | 用途 | 使用场景 |
|------|------|---------|
| 绿色 | 成功/正常 | ✓ 通过的检查、成功的操作 |
| 红色 | 错误/失败 | ✗ 失败的检查、错误信息 |
| 黄色 | 警告/注意 | ⚠ 警告信息、需注意的项 |
| 蓝色 | 标题/步骤 | 章节标题、步骤说明 |
| 青色 | 信息/提示 | ℹ 普通信息、提示内容 |
| 灰色 | 次要信息 | 详细说明、补充内容 |

### 符号使用规范

| 符号 | 含义 | 使用场景 |
|------|------|---------|
| ✓ | 成功/通过 | 检查通过、操作成功 |
| ✗ | 失败/错误 | 检查失败、操作失败 |
| ⚠ | 警告/注意 | 需要注意的项目 |
| ℹ | 信息 | 提示信息 |
| → | 步骤/进度 | 当前执行的步骤 |
| ○ | 跳过 | 跳过的检查项 |
| • | 列表项 | 普通列表项 |

### 分隔线使用

```
双线分隔（强调）：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

单线分隔（表格）：
────────────────────────────────────────

等号分隔（传统）：
====================================================

虚线分隔（轻量）：
- - - - - - - - - - - - - - - - - - - - - - - - -
```

## 🔧 自定义输出

### 在新脚本中使用

```bash
#!/bin/bash
# 你的脚本

# 加载格式化库
PROJECT_DIR=/root/setup_cdh_cluster
source "$PROJECT_DIR/lib/output_formatter.sh"

# 显示横幅
print_banner "你的脚本名称" "脚本说明" "作者"

# 显示步骤
print_header "步骤 1: 初始化"
log_step "正在初始化..."
log_success "初始化完成"

# 显示表格
print_header "结果汇总"
print_table_header
print_table_row "项目" "状态"
print_single_line
print_table_row "配置" "完成"
print_single_line

# 显示最终结果
print_success_header "操作完成"
```
