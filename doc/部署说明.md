# CDH 集群三节点部署说明

## 集群节点配置

本项目已配置为三节点部署模式：

| 角色 | 主机名 | IP地址 | 说明 |
|------|--------|--------|------|
| master | node01 | 192.168.56.151 | 主节点，部署MySQL、Cloudera Manager Server |
| slave | node02 | 192.168.56.152 | 从节点，计算节点 |
| slave | node03 | 192.168.56.153 | 从节点，计算节点 |

## 部署前准备工作

### 1. 配置主机名和hosts映射

在**所有节点**上执行：

```bash
# 编辑 /etc/hosts 文件
vi /etc/hosts

# 添加以下内容
192.168.56.151  node01
192.168.56.152  node02
192.168.56.153  node03
```

### 2. 配置SSH免密登录

在**node01主节点**上执行：

```bash
# 安装openssh客户端
yum -y install openssh-clients

# 生成SSH密钥对（一路回车）
ssh-keygen -t rsa

# 将公钥复制到所有节点
ssh-copy-id root@node01
ssh-copy-id root@node02
ssh-copy-id root@node03

# 测试免密登录
ssh node02
ssh node03
```

### 3. 安装Ansible

在**node01主节点**上执行：

```bash
# 安装Ansible 2.8
yum install -y centos-release-ansible-28.noarch

# 验证安装
ansible --version
```

### 4. 配置Ansible主机清单

将项目中的hosts文件复制到ansible配置目录：

```bash
# 备份原有hosts文件
cp /etc/ansible/hosts /etc/ansible/hosts.bak

# 复制项目配置文件
cp ${your_path}/setup_cdh_cluster/ansible/node_group/hosts /etc/ansible/hosts

# 验证配置
ansible all_node --list-hosts
```

预期输出应该包含：node01、node02、node03

### 5. 上传组件安装包

将下载的组件安装包解压并上传到**node01节点**：

```bash
# 确保以下两个目录存在且包含所需文件
/opt/base_file/packages
/opt/base_file/parcels
```

**packages目录**应包含：
- JDK安装包
- MySQL相关RPM包
- Cloudera Manager RPM包
- MySQL驱动jar包等

**parcels目录**应包含：
- CDH parcel文件
- KAFKA parcel文件
- SPARK2 parcel文件
- manifest.json

## 开始部署

在**node01主节点**上执行部署命令：

```bash
# 执行部署脚本
ansible-playbook ${your_path}/setup_cdh_cluster/ansible/deploy_cdh.yml
```

部署过程会自动完成以下步骤：
1. 配置系统环境（关闭防火墙、SELinux等）
2. 安装Java、Scala、Python环境
3. 配置本地YUM仓库
4. 安装MySQL Server（仅node01）
5. 安装Cloudera Manager
6. 配置CDH服务

## 常见问题

### cloudera-scm-server无法启动

查看日志排查问题：
```bash
tail -f /var/log/cloudera-scm-server/cloudera-scm-server.log
```

### 防火墙问题

确保所有节点防火墙已关闭或开放必要端口：
```bash
# 关闭防火墙
systemctl stop firewalld
systemctl disable firewalld

# 查看防火墙状态
systemctl status firewalld
```

### SELinux问题

确保SELinux已禁用：
```bash
# 临时禁用
setenforce 0

# 永久禁用（编辑配置文件）
vi /etc/selinux/config
# 设置 SELINUX=disabled
```
