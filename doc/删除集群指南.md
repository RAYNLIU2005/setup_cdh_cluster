## ⚠️ 重要警告

**此操作将完全删除 CDH 集群，所有数据将无法恢复！**

### 🛡️ 安全保护措施

**会保留的内容**：
- ✅ `/opt/base_file` 目录（安装包，重新部署需要）
- ✅ 系统关键服务（sshd, network, systemd 等）
- ✅ 系统配置文件
- ✅ 非 CDH 相关的进程和服务

**会删除的内容**：
- ❌ Cloudera Manager（Server & Agent）
- ❌ MySQL 数据库（CDH 专用）
- ❌ Java 和 Scala
- ❌ CDH 数据目录
- ❌ CDH 配置和日志

请在执行前确认：
- ✓ 已备份重要数据
- ✓ 确认不再需要此集群
- ✓ 了解删除的影响范围

---

## 🗑️ 删除命令

### 快速删除

```bash
cd /root/setup_cdh_cluster

# 执行删除
make delall
```

### 执行流程

1. **确认提示**
   ```
   确认删除所有 CDH 集群？输入 'DELETE' 继续:
   ```
   输入 `DELETE`（必须大写）

2. **最终确认**
   ```
   最后确认：真的要删除吗？[yes/no]:
   ```
   输入 `yes`

3. **自动执行删除**
   脚本会自动完成所有删除操作

## ⚠️ 注意事项

### 1. 数据备份

删除前务必备份：
- MySQL 数据库
- HDFS 数据
- 配置文件
- 自定义脚本

### 2. 确认操作

- 必须输入 `DELETE`（大写）
- 必须输入 `yes` 最终确认
- 两次确认防止误操作

### 3. 网络要求

- 需要所有节点的 SSH 访问权限
- 建议在 master 节点（node01）执行

### 4. 执行时间

- 预计耗时：5-10 分钟
- 取决于集群规模和数据量

### 5. 不可恢复

- 删除操作不可逆
- 无法恢复已删除的数据
- 请谨慎操作

## 🛠️ 故障处理

### 问题 1: 删除失败

**现象**：某些组件删除失败

**解决**：
```bash
# 查看详细错误
bash -x /root/setup_cdh_cluster/scripts/delete_cluster.sh

# 手动清理残留
rm -rf /opt/cloudera
rm -rf /var/lib/cloudera-*
```

### 问题 2: SSH 连接失败

**现象**：无法连接到其他节点

**解决**：
```bash
# 检查 SSH 连接
make nodes

# 配置 SSH 免密
make setup-ssh

# 重新执行删除
make delall
```

### 问题 3: 服务无法停止

**现象**：某些服务停止失败

**解决**：
```bash
# 强制停止所有服务
make force-stop

# 再次执行删除
make delall
```

## 📝 手动删除

如果自动删除失败，可以手动执行：

### 1. 停止服务

```bash
# 所有节点执行
systemctl stop cloudera-scm-agent
systemctl stop cloudera-scm-server
systemctl stop mysqld
systemctl stop httpd
```

### 2. 卸载软件

```bash
# 所有节点执行
yum remove -y cloudera-manager-*
yum remove -y mysql-community-*
```

### 3. 删除目录

```bash
# 所有节点执行
rm -rf /opt/cloudera
rm -rf /var/lib/cloudera-*
rm -rf /var/log/cloudera-*
rm -rf /usr/java
rm -rf /var/lib/mysql
```

### 4. 清理配置

```bash
# 所有节点执行
sed -i '/JAVA_HOME/d' /etc/profile
sed -i '/SCALA_HOME/d' /etc/profile
rm -f /etc/yum.repos.d/cloudera*.repo
```

## 🔍 验证删除

删除完成后验证：

```bash
# 检查服务状态
systemctl status cloudera-scm-server
systemctl status cloudera-scm-agent
systemctl status mysqld

# 检查目录
ls /opt/cloudera
ls /var/lib/cloudera-scm-server

# 检查进程
ps aux | grep cloudera
ps aux | grep mysql

# 检查端口
netstat -tlnp | grep 7180
netstat -tlnp | grep 3306
```

如果都没有输出，说明删除成功！
