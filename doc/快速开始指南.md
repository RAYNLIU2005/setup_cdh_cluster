# CDH集群快速开始指南

## 项目优化说明

本项目已进行全面优化，包括：
- ✅ **磁盘空间优化**：使用软链接替代文件复制，节省约1-2GB空间
- ✅ **日志管理**：统一日志记录到`/var/log/cdh_deploy.log`
- ✅ **错误处理**：添加详细的错误提示和日志记录
- ✅ **便捷脚本**：提供一键式管理脚本
- ✅ **部署验证**：自动化验证部署状态

---

## 环境要求

### 硬件要求
- **磁盘空间**：每个节点至少30GB可用空间（推荐40GB）
- **内存**：每个节点至少2GB（推荐4GB）
- **CPU**：至少2核

### 软件要求
- **操作系统**：CentOS 7.x
- **Python**：2.7.5+
- **Ansible**：2.8+（仅主节点）

## 快速部署步骤

### 1. 准备工作（所有节点）

#### 配置主机名和hosts映射

在**所有节点**上执行：
```bash
cat >> /etc/hosts << EOF
192.168.56.151  node01
192.168.56.152  node02
192.168.56.153  node03
EOF
```

#### 配置SSH免密登录（仅node01）

```bash
# 在node01上执行
yum -y install openssh-clients
ssh-keygen -t rsa -N "" -f ~/.ssh/id_rsa
ssh-copy-id root@node01
ssh-copy-id root@node02
ssh-copy-id root@node03

# 测试
ssh node02 "hostname"
ssh node03 "hostname"
```

### 2. 安装Ansible（仅node01）

```bash
# 在node01上执行
yum install -y centos-release-ansible-28.noarch
ansible --version
```

### 3. 上传项目和安装包

将以下内容上传到**node01**节点：
```
/root/setup_cdh_cluster/          # 项目目录
/opt/base_file/packages/          # 安装包目录
/opt/base_file/parcels/           # Parcel文件目录
```

### 4. 配置Ansible主机清单

```bash
# 在node01上执行
cp /root/setup_cdh_cluster/ansible/node_group/hosts /etc/ansible/hosts

# 验证配置
ansible all_node --list-hosts
```

### 5. 检查磁盘空间（重要！）

```bash
# 使用管理脚本检查
cd /root/setup_cdh_cluster
chmod +x scripts/manage_cluster.sh
./scripts/manage_cluster.sh check
```

如果磁盘空间不足，执行清理：
```bash
./scripts/manage_cluster.sh clean
```

### 6. 执行部署

#### 方法1：使用管理脚本（推荐）
```bash
cd /root/setup_cdh_cluster
./scripts/manage_cluster.sh deploy
```

#### 方法2：直接使用ansible-playbook
```bash
cd /root/setup_cdh_cluster
ansible-playbook -i ansible/node_group/hosts ansible/deploy_cdh.yml
```

### 7. 验证部署

```bash
# 验证部署状态
./scripts/manage_cluster.sh verify

# 查看服务状态
./scripts/manage_cluster.sh status

# 查看部署日志
./scripts/manage_cluster.sh logs
```

## 故障排查

### 1. 磁盘空间不足

**症状**：`No space left on device`

**解决方案**：
```bash
# 清理系统
./scripts/manage_cluster.sh clean

# 或手动清理
yum clean all
rm -rf /tmp/* /root/.ansible/tmp/*
journalctl --vacuum-size=100M
```

### 2. 服务无法启动

**检查服务状态**：
```bash
./scripts/manage_cluster.sh status
```

**查看详细日志**：
```bash
# CM Server日志
tail -f /var/log/cloudera-scm-server/cloudera-scm-server.log

# CM Agent日志
tail -f /var/log/cloudera-scm-agent/cloudera-scm-agent.log

# MySQL日志
tail -f /var/log/mysqld.log

# 部署日志
tail -f /var/log/cdh_deploy.log
```

### 3. 网络连接问题

**测试节点连通性**：
```bash
ansible all_node -i /etc/ansible/hosts -m ping
```

### 4. 重新部署

如果需要重新部署：
```bash
# 1. 清理系统
./scripts/manage_cluster.sh clean

# 2. 重新部署
./scripts/manage_cluster.sh deploy
```

## 磁盘空间优化说明

本项目已优化磁盘使用：

1. **软链接替代复制**：本地YUM仓库使用软链接而不是复制文件
2. **按需分发文件**：只分发必需的安装包到从节点
3. **跳过系统更新**：跳过全量系统更新以节省时间和空间
4. **自动清理缓存**：部署过程中自动清理YUM缓存

预计节省空间：**1-2GB**
