## 问题描述

**现象**：Cloudera Manager 界面只显示 1 个节点（node01），缺少 node02 和 node03

**原因**：
1. 部署时只配置了一个节点
2. node02、node03 的 CM Agent 未安装或未启动
3. 网络或 SSH 连接问题

### 方案 2：手动在 CM 界面添加

#### 2.1 访问 CM 界面

```
http://node01:7180
或
http://192.168.56.151:7180
```

#### 2.2 添加主机

1. 点击 **Hosts** > **Add Hosts**
2. 在 **Specify Hosts** 页面输入：
   ```
   node02
   node03
   ```
   或使用 IP：
   ```
   192.168.56.152
   192.168.56.153
   ```

3. 点击 **Continue**

4. 选择仓库：
   - 使用现有的本地仓库
   - 或指向：`http://node01/cloudera-repos/cm6/6.3.1/`

5. 安装 Agent 并等待完成

6. 添加到现有集群

#### 2.3 分配角色

根据您的需求分配角色：
- **DataNode**：node02, node03
- **NodeManager**：node02, node03
- **RegionServer**：node02, node03（如果使用 HBase）

### 方案 3：手动命令行添加

如果自动脚本失败，手动执行：

#### 3.1 在 node02 上执行

```bash
# SSH 到 node02
ssh node02

# 1. 安装 Java（如果没有）
sudo mkdir -p /usr/java
# 从 node01 复制 Java
# 或手动安装

# 2. 配置 YUM 仓库
sudo cat > /etc/yum.repos.d/cloudera-manager.repo <<EOF
[cloudera-manager]
name=Cloudera Manager
baseurl=http://node01/cloudera-repos/cm6/6.3.1/redhat7/yum/
gpgcheck=0
enabled=1
EOF

# 3. 安装 CM Agent
sudo yum install -y cloudera-manager-agent cloudera-manager-daemons

# 4. 配置 Agent
sudo sed -i 's/server_host=.*/server_host=node01/' /etc/cloudera-scm-agent/config.ini

# 5. 启动 Agent
sudo systemctl start cloudera-scm-agent
sudo systemctl enable cloudera-scm-agent

# 6. 检查状态
sudo systemctl status cloudera-scm-agent
```

#### 3.2 在 node03 上执行

重复上述步骤。

### 标准 3 节点配置

| 节点 | 角色 | 服务 |
|------|------|------|
| **node01** | Master | NameNode, ResourceManager, CM Server, MySQL |
| **node02** | Worker | DataNode, NodeManager |
| **node03** | Worker | DataNode, NodeManager |

**核心服务**（node01）：

## ⚠️ 故障排查

### 问题 1：Agent 无法连接到 Server

**症状**：Agent 日志显示连接失败

**解决**：
```bash
# 检查网络
ping node01

# 检查防火墙
sudo systemctl status firewalld
sudo firewall-cmd --list-all

# 检查 CM Server 状态
ssh node01 'systemctl status cloudera-scm-server'

# 检查配置
cat /etc/cloudera-scm-agent/config.ini | grep server_host
```

### 问题 2：SSH 连接失败

**症状**：make add-nodes 报 SSH 错误

**解决**：
```bash
# 配置 SSH 免密登录
make setup-ssh

# 测试 SSH
make test-ssh
```

### 问题 3：Java 未安装

**症状**：Agent 启动失败，提示 Java 错误

**解决**：
```bash
# 从 node01 复制 Java
scp -r /usr/java/jdk* node02:/usr/java/
ssh node02 'ln -sf /usr/java/jdk* /usr/java/default'

# 配置环境变量
ssh node02 'cat >> /etc/profile <<EOF
export JAVA_HOME=/usr/java/default
export PATH=\$PATH:\$JAVA_HOME/bin
EOF'
```

### 问题 4：YUM 仓库无法访问

**症状**：yum install 失败

**解决**：
```bash
# 检查 httpd 服务（在 node01）
systemctl status httpd

# 测试仓库访问
curl http://node01/cloudera-repos/

# 重新配置仓库
sudo cat > /etc/yum.repos.d/cloudera-manager.repo <<EOF
[cloudera-manager]
name=Cloudera Manager
baseurl=http://node01/cloudera-repos/cm6/6.3.1/redhat7/yum/
gpgcheck=0
enabled=1
EOF

sudo yum clean all
```
